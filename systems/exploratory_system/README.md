An exploratory multi-agent system extending smolagents. It employs a hierarchical search pipeline (BM25 → Hybrid RAG + BM25 → DCI) and implements a persistent Knowledge Base [1] alongside a Tree Execution Plan [2]. The system utilizes an Explorer agent for proactive probing and a Supervisor agent for executing path evaluations.
